# 🚩 大電視觸控雙人拔河對戰遊戲 (Classroom Interactive Tug of War)

專為中小學教室大螢幕觸控電視（65 ~ 86 吋電子白板）與雙人競賽設計的即時對戰網頁遊戲。學生分站大螢幕左右兩端進行搶答，先達決勝門檻者獲勝！

## ✨ 核心特色與大螢幕專屬優化

1. 🚫 **防止原生虛擬鍵盤彈出**：採用自製虛擬觸控顯示條與大按鍵，點擊時**絕不會彈出 Windows 或 Android 系統螢幕鍵盤**，維持完整比賽畫面。
2. ⚡ **雙人多點觸控零延遲**：左右兩隊獨立運作，採用 `pointerdown` 監聽，支援兩位學生同時間快速按鍵作答，互不衝突。
3. 🎮 **4 大版本獨立切換（新登場）**：
   * **🎯 標準綜合版**：經典四則運算、幾何度量、國語自然趣味搶答。
   * **🔢 小數運算版**：專屬鍵盤新增 `.` 小數點按鍵，支援小數加減乘除與數值等價判定。
   * **🍰 分數對決版**：直式分數精美排版，鍵盤新增 `/` 分數線與 `又` 帶分數鍵，支援帶分數假分數等值換算。
   * **🔤 低年級注音版**：整合 `render-zhuyin-web`，國字旁直式標註教育部標準注音符號（含聲調輕聲），識字低年級也能輕鬆讀題！
4. 🎵 **震撼熱血背景音樂與音量微調**：內建熱血 BGM 循環播放（預設 80% 飽滿音量），頂部右側 HUD 提供 `🔉 -`、`80%`、`🔊 +` 快速調節鍵，設定彈窗亦提供精準滑桿微調與本機記憶。
5. 🔊 **100% 離線 Web Audio 音效**：完全使用瀏覽器原生音訊合成（答對和弦音、答錯警示音、按鍵音、獲勝號角），無須聯網載入任何 MP3 音效檔，且音量與背景音樂連動同步。
6. 🎨 **生動 SVG 拔河動態**：包含拔河選手發力傾斜動畫、咬牙汗珠、答對猛拉動作、地表揚起煙塵與中心紅標平移。
7. 🎊 **勝利彩紙特效**：淨勝步數達標（預設 5 步）時，觸發全螢幕 Canvas Confetti 彩紙與結算獎盃。
8. 📝 **超彈性題庫替換與全場不重複**：
   * **保證不重複**：智慧題目池控管，全場絕不出現重複題目。
   * **百題高容量**：支援最多 100 道題庫（以答案數計算，長篇題目亦支援）。
   * **四版本完全隔離**：各版本題庫儲存互不干擾，現場可隨時恢復各版本預設題庫。
9. 🛡️ **著作權浮水印**：網頁角落常駐「Created by 祐誠老師」專屬標籤，質感高雅且具備點擊穿透保護。

## 📖 題庫替換格式說明

在遊戲中點擊左上角 **「⚙️ 題庫設定」**，輸入格式為：
```text
題目, 答案
```
* 每行一題，題目與答案之間用逗號（半形或全形皆可）隔開。
* 答案支援數字或字母。

### 常用學科題庫範例

#### 數學科（四則運算與因倍數）
```text
8 × 9 = ?, 72
125 ÷ 5 = ?, 25
最小的質數是？, 2
12 和 18 的最大公因數是？, 6
```

#### 自然科學
```text
成人全身骨骼大約有幾塊？, 206
常溫常壓下水沸騰是幾度C？, 100
昆蟲有幾隻腳？, 6
太陽系目前有幾大行星？, 8
```

#### 國語文成語填空
```text
「( )面楚歌」應填入？, 4
「( )上( )下」形容心神不定？, 78
「( )言( )鼎」比喻說話有份量？, 19
「垂涎( )尺」應填入？, 3
```

## 🔒 資安與隱私合規

- **個資保護**：本遊戲不收集、不傳輸、不儲存任何學生個人資料（如姓名、學號、IP 等）。
- **DOM 安全**：全數使用原生 `textContent` 與受控虛擬按鍵，完全杜絕 XSS 跨站腳本攻擊風險。
- **純靜態架構**：無後端伺服器依賴、無資料庫外洩風險，可 100% 離線在班級電腦安全執行。
