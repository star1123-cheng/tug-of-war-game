# 🚩 大電視觸控雙人拔河對戰遊戲 (Classroom Interactive Tug of War)

專為中小學教室大螢幕觸控電視（65 ~ 86 吋電子白板）與雙人競賽設計的即時對戰網頁遊戲。學生分站大螢幕左右兩端進行搶答，先達決勝門檻者獲勝！

## ✨ 核心特色與大螢幕專屬優化

1. 🚫 **防止原生虛擬鍵盤彈出**：採用自製虛擬觸控顯示條與大按鍵，點擊時**絕不會彈出 Windows 或 Android 系統螢幕鍵盤**，維持完整比賽畫面。
2. ⚡ **雙人多點觸控零延遲**：左右兩隊獨立運作，採用 `pointerdown` 監聽，支援兩位學生同時間快速按鍵作答，互不衝突。
3. 🔊 **100% 離線 Web Audio 音效**：完全使用瀏覽器原生音訊合成（答對和弦音、答錯警示音、按鍵音、獲勝號角），無須聯網載入任何 MP3 音效檔。
4. 🎨 **生動 SVG 拔河動態**：包含拔河選手發力傾斜動畫、咬牙汗珠、答對猛拉動作、地表揚起煙塵與中心紅標平移。
5. 🎊 **勝利彩紙特效**：淨勝步數達標（預設 5 步）時，觸發全螢幕 Canvas Confetti 彩紙與結算獎盃。
6. 📝 **超彈性題庫替換**：
   * **現場即時貼上**：點擊右上角「⚙️ 題庫設定」，直接貼上 `題目, 答案`，自動儲存於瀏覽器快取。
   * **程式碼自訂**：亦可在原始碼 `DEFAULT_QUESTION_BANK` 直接配置。

## 📖 題庫替換格式說明

在遊戲中點擊左上角 **「⚙️ 題庫設定」**，輸入格式為：
```text
題目, 答案
```
* 每行一題，題目與答案之間用逗號（半形或全形皆可）隔開。
* 答案支援數字或字母。

### 常用學科題庫範例

#### 數學科（四則運算與因倍數）
```text
8 × 9 = ?, 72
125 ÷ 5 = ?, 25
最小的質數是？, 2
12 和 18 的最大公因數是？, 6
```

#### 自然科學
```text
成人全身骨骼大約有幾塊？, 206
常溫常壓下水沸騰是幾度C？, 100
昆蟲有幾隻腳？, 6
太陽系目前有幾大行星？, 8
```

#### 國語文成語填空
```text
「( )面楚歌」應填入？, 4
「( )上( )下」形容心神不定？, 78
「( )言( )鼎」比喻說話有份量？, 19
「垂涎( )尺」應填入？, 3
```

## 🔒 資安與隱私合規

- **個資保護**：本遊戲不收集、不傳輸、不儲存任何學生個人資料（如姓名、學號、IP 等）。
- **DOM 安全**：全數使用原生 `textContent` 與受控虛擬按鍵，完全杜絕 XSS 跨站腳本攻擊風險。
- **純靜態架構**：無後端伺服器依賴、無資料庫外洩風險，可 100% 離線在班級電腦安全執行。
